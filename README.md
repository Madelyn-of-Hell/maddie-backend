## Webring

1. Create a pr adding yourself to `webring.json`. Member entries should be of the form:
```json
{
  "name": "<Choose a name>",
  "url": "<Your site's URL>"
}
```
2. Add links to your website pointing to
- `https://oneluckymushroom.dev/webring/next/?source=<Your name>`
- `https://oneluckymushroom.dev/webring/previous/?source=<Your name>`
- `https://oneluckymushroom.dev/webring/random/?source=<Your name>`

Once the pr is accepted the webring will need to be re-booted, and then your buttons should work !
Don't be concerned if this takes a bit; it's a human action, not automatic.
